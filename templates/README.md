# Templates

Starter files for building new pages on the off-the-record site.
These are clean copies of the chapter-page architecture (template-1 pattern).

When building a new page:
1. Copy whichever template fits your needs
2. Rename it
3. Swap out the content
4. Move it to the root directory when ready to publish

DO NOT edit these directly — always copy first.

- template-1.html = Standard reader page (full CSS, header, TOC, auth)
- template-2.html = Admin tool page
- template-3.html = Standalone page (self-contained)
- template-4.html = Development tool
- template-5.html = Blank slate
